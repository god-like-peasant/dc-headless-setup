Desktop Commander Headless Setup for Windows

A free, source-included installer for the official Desktop Commander Remote Device. It adds quiet startup at Windows sign-in, bounded process recovery, logs, and status checks. No paid hosting, paid software, or machine-wide administrator install is required for the user-local Node.js fallback.

Download the setup kit

On the target Windows computer, download the ZIP and choose Extract All. In the extracted folder, right-click Install-DesktopCommander.ps1 and choose Run with PowerShell. Do not run as Administrator.

One-time human authorization is required. The installer displays a URL and code for the official device-authorization flow. Compare the code character-for-character and approve only if it matches. Browsers do not automatically run downloaded installers or scripts from a URL.

After first pairing

A per-user Windows Scheduled Task starts a hidden supervisor at sign-in. It restarts exited processes with bounded backoff and can restart an agent after sustained known connection-error markers. It cannot bypass OAuth or guarantee internet/cloud availability.

Hotspot and Wi-Fi notes

Review Settings > Network & internet > Mobile hotspot and disable its Power saving switch if your Windows version offers one and you accept the battery trade-off. The kit does not change driver-specific Wi-Fi settings or force private Windows hotspot behavior. Sleep, battery depletion, drivers, and external hotspots can still interrupt service.
