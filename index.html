Desktop Commander Windows Setup Kit

A free, source-included kit to install and run the official Desktop Commander Remote Device for the signed-in Windows user.

Download Windows setup ZIP

Automatic download and setup

In a normal (non-administrator) PowerShell window, paste this command. It downloads and checksum-verifies the ZIP, extracts the kit, then starts setup:

$p=Join-Path $env:TEMP 'Bootstrap-DesktopCommander.ps1'; Invoke-WebRequest -UseBasicParsing 'https://raw.githubusercontent.com/god-like-peasant/dc-headless-setup/main/Bootstrap-DesktopCommander.ps1' -OutFile $p; powershell.exe -NoProfile -ExecutionPolicy Bypass -File $p

Chrome can download a script but cannot run it automatically. First-time pairing remains visible: compare the displayed one-time code before approving.

View release and checksums · Read setup and safety notes

Authorization required: First setup opens the official device authorization flow. Compare the one-time code shown on the Windows computer with the code in the browser before you approve. Remote calls run locally with the Windows user's permissions. This kit does not provide unattended authorization.

The kit uses a limited-privilege per-user scheduled task for sign-in startup and bounded process restart. Internet, valid authorization, service availability, and hotspot uptime are not guaranteed. It has not been tested on a physical Windows computer.

Free and open source. No paid hosting, domain, subscription, or payment method required.
